# Quotation Comparison Matrix

## Purpose

The matrix compares vendor quotations side by side and supports recommendation decisions.

## Criteria

- total price
- delivery time
- vendor score
- compliance
- warranty or terms
- item coverage

## Behavior

Lowest price and fastest delivery are highlighted independently. Sorting supports price, delivery, score, compliance, and weighted recommendation. Vendor users must never access this matrix.

## Visual Rules

Use a fixed left criteria column and vendor columns to the right. Best values use green highlight with a subtle left accent.
