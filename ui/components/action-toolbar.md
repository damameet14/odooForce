# Action Toolbar

## Purpose

Action toolbars provide consistent search, filters, sorting, bulk actions, and export across tables.

## Anatomy

- search field
- filter controls
- sort selector
- bulk action menu
- export button
- optional document actions such as PDF, print, and email

## Behavior

Toolbars should remain compact and wrap gracefully on small screens. Actions are role-aware and should be disabled or hidden when unavailable.
