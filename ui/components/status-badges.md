# Status Badges

## Purpose

Badges encode workflow state and exception severity without requiring users to read long descriptions.

## Mapping

| Status Type | Color |
| --- | --- |
| Draft or inactive | Gray |
| Sent or submitted | Blue |
| Quotes received or action focus | Coral |
| Pending or due soon | Amber |
| Approved, paid, complete | Green |
| Rejected, overdue, SLA breach | Red |

## Behavior

Badges are display components only. They should not replace permission checks or workflow validation.
