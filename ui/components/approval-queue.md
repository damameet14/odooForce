# Approval Queue

## Purpose

The approval queue gives Finance Officers a prioritized view of procurement decisions.

## Anatomy

- approval ID
- RFQ reference
- selected vendor
- value
- SLA or due timer
- status
- decision actions

## Behavior

Approve, reject, and request changes appear only for Finance Officers. Rejection and change requests require a reason. Decision actions should later create activity logs and notifications in the same transaction as the state update.
