# Analytics Widgets

## Purpose

Analytics widgets expose procurement performance, spend, bottlenecks, and vendor quality.

## Widget Types

- spend trend
- RFQ funnel
- vendor performance
- approval turnaround
- category spending
- monthly analytics

## Behavior

Widgets support filters for date range, category, vendor, and workflow status when implemented. Vendor users must not see organization-wide analytics.

## Visual Rules

Use restrained chart colors from the design tokens. Pair color with labels so state is accessible and scannable.
