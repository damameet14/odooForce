# KPI Cards

## Purpose

KPI cards summarize operational state at the top of the dashboard and report pages.

## Anatomy

- label
- primary value
- trend or exception line
- optional status tint

## Behavior

Each KPI opens a filtered page view. Examples: Active RFQs opens RFQs with active statuses, Pending Approvals opens the finance approval queue, Open Invoices opens unpaid invoices.

## Visual Rules

Use white card surfaces, 8px radius, warm border, and a compact 118px minimum height. KPI values use the strongest type weight on the page.
