# Workflow Pipeline

## Purpose

The workflow pipeline makes the procurement lifecycle visible across RFQs, approvals, and POs.

## States

- Draft
- Sent
- Quotes Received
- Approval Pending
- Approved
- PO Generated

## Behavior

Pipeline stages act as filters in list pages and as progress indicators in detail pages. Current state uses coral, completed state uses green, future state uses neutral border.

## Visual Rules

Use compact stage blocks with count, value, and helper metadata. Avoid oversized timeline graphics; this is an operational ERP control.
