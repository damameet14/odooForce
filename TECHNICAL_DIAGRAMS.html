3. Procurement Workflow

RFQ to invoice with enforcement points
Create RFQOfficer selects catalog products, quantities, and vendors per item.
Validate RFQActive products, positive quantities, and item vendor assignments.
Send RFQVendors receive notifications for assigned items.
Vendor GateOnly assigned vendorId can access and quote item lines.
Submit QuoteAssigned items priced with GST and delivery days.
Best QuoteCompare per item and calculate cheapest valid combination.
Manager ApprovalApproval required before PO generation.
PO + InvoiceVendor-wise POs, delivery receipt, PDF/email, payment tracking.

5. API Sequence

Main transaction path from user setup to document email

Admin

POST /api/usersCreate internal user with validated role, phone, password.
POST /api/productsCreate catalog products with category, unit, and GST.
PUT /api/password-reset-requests/:idApprove or reject reset requests.

Officer

POST /api/rfqsCreate product-based RFQ with vendors per item.
POST /api/rfqs/:id/sendMove RFQ to SENT and notify vendors.
POST /api/rfqs/:id/best-quoteCalculate cheapest item-vendor combination.
POST /api/purchase-orders/generateCreate vendor-wise POs after approval.

Vendor

GET /vendor/rfqs/:idOwnership check using linked vendorId and item assignments.
POST /api/quotationsSubmit assigned item pricing, GST, and delivery days.
PUT /api/purchase-orders/:id/statusAdvance own delivery progress.

Manager

GET /api/reports/*Review spend, vendor performance, RFQ summary.
PUT /api/approvals/:id/approveApprove selected item-vendor combination.
PUT /api/invoices/:id/payment-statusTrack invoice payment state.

Documents

GET /api/purchase-orders/:id/pdfStream purchase order PDF.
GET /api/invoices/:id/pdfStream invoice PDF.
Email endpointsSend through Brevo and store EmailLog.

6. Security and Validation

Authentication, RBAC, vendor isolation, and workflow guards
RequestBearer token from frontend Axios client.
JWT Valid?No token returns 401.
Role Allowed?authorize(...) returns 403.
Payload Valid?express-validator returns 422.
Vendor Owned?Vendor records checked with req.user.vendorId.
State Valid?Deadline, locks, approval, duplicate checks.
TransactionState change, log, and notification commit together.
